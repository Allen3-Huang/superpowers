# 執行計畫

## 概述

載入計畫、批判性審查、執行所有任務、完成後回報。

**開始時宣告：**「我正在使用 executing-plans 技能來實作此計畫。」

**注意：** 告知您的人工夥伴，Superpowers 在可存取子代理人的情況下效果更佳。如果在支援子代理人的平台上執行（如 Claude Code 或 Codex），其工作品質將顯著提升。如果子代理人可用，請使用 superpowers:subagent-driven-development 而非此技能。

## 流程

### 步驟 1：載入並審查計畫
1. 讀取計畫檔案
2. 批判性審查——識別任何關於計畫的問題或顧慮
3. 如有顧慮：在開始前與您的人工夥伴提出
4. 如無顧慮：建立 TodoWrite 並繼續

### 步驟 2：執行任務

對於每個任務：
1. 標記為進行中
2. 精確遵循每個步驟（計畫包含分解好的步驟）
3. 按指定執行驗證
4. 標記為已完成

### 步驟 3：完成開發

所有任務完成並驗證後：
- 宣告：「我正在使用 finishing-a-development-branch 技能來完成此工作。」
- **必要子技能：** 使用 superpowers:finishing-a-development-branch
- 遵循該技能以驗證測試、呈現選項、執行選擇

## 何時停止並尋求協助

**立即停止執行當：**
- 遇到阻礙（缺少依賴、測試失敗、指令不清晰）
- 計畫有嚴重缺口導致無法開始
- 您不理解某個指令
- 驗證反覆失敗

**尋求澄清而非猜測。**

## 何時重新審視先前步驟

**返回審查（步驟 1）當：**
- 夥伴根據您的回饋更新了計畫
- 基本方法需要重新思考

**不要強行突破阻礙** — 停下來詢問。

## 注意事項
- 先批判性審查計畫
- 精確遵循計畫步驟
- 不要跳過驗證
- 計畫說明時參考技能
- 遇到阻礙時停止，不要猜測
- 未經使用者明確同意，絕不在 main/master 分支上開始實作

## 整合

**必要的工作流程技能：**
- **superpowers:using-git-worktrees** — 必要：在開始前設定隔離的工作區
- **superpowers:writing-plans** — 建立此技能執行的計畫
- **superpowers:finishing-a-development-branch** — 所有任務完成後完成開發
